# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-08

### Added
- Initial release of Backify CLI.
- Scaffolding support for Express with PostgreSQL/Prisma or MongoDB/Mongoose.
- Choice of MVC or Service-Repository architecture.
- Pre-configured JWT Authentication and Zod Validation.
- ES Modules support and environment configuration.
- Comprehensive open-source guidelines (Contributing, Code of Conduct, Security, Support).
- GitHub Issue and PR templates.
- GitHub Actions CI workflow for linting and testing.
