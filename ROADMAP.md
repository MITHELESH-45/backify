# Backify Roadmap

This document outlines the future plans and upcoming features for Backify. Our goal is to make Backify the most versatile and robust backend generator available.

## Upcoming Features

### Framework & Language Support
- [ ] **TypeScript Template**: First-class support for generating TypeScript backends.
- [ ] **FastAPI Support**: Python scaffolding with FastAPI and SQLAlchemy/Motor.
- [ ] **Spring Boot Support**: Java/Kotlin scaffolding for enterprise applications.
- [ ] **NestJS Support**: Highly opinionated Node.js framework scaffolding.

### Features & Integrations
- [ ] **Docker Support**: Generate `Dockerfile` and `docker-compose.yml` for instant local environments.
- [ ] **Authentication Providers**: Out-of-the-box support for OAuth2 (Google, GitHub, etc.) and Magic Links.
- [ ] **Microservices Scaffolding**: Generate API Gateways and microservice templates with gRPC or RabbitMQ communication.

### Developer Experience (DX)
- [ ] **Testing Templates**: Pre-configured Jest/Supertest or Vitest setups in the generated code.
- [ ] **CI/CD Templates**: Option to generate GitHub Actions or GitLab CI pipelines in the scaffolded project.

*Note: This roadmap is subject to change based on community feedback and priorities. If you want to contribute to any of these features, please check our [CONTRIBUTING.md](CONTRIBUTING.md).*
