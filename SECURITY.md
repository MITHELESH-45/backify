# Security Policy

## Supported Versions

Please see the table below for the versions of Backify that are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Backify seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by email or via the GitHub Security Advisory "Report a vulnerability" feature if enabled.
Once we receive your report, we will try to acknowledge it within 48 hours, and we will provide a timeline for a fix.
When the issue is resolved, we will publish a security advisory and credit you for the discovery.
