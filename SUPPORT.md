# Support

Welcome to the Backify support guide! If you have questions, run into issues, or want to suggest new features, here is how you can get help.

## How to Get Help

### 1. Check the Documentation
Before asking a question, please look through the [README.md](README.md) and [FAQ](README.md#faq) sections. Your question might already be answered!

### 2. Search Existing Issues
Check the [GitHub Issues](https://github.com/your-username/backify/issues) to see if someone else has already reported your problem or requested the same feature. If you find an existing issue, please add a "thumbs up" reaction to it or provide additional context in the comments.

### 3. Open a New Issue
If you can't find an answer, feel free to open an issue:
- **Bug Report**: If you found a bug, please use the Bug Report template and provide as much detail as possible (logs, screenshots, steps to reproduce).
- **Feature Request**: If you have an idea for a new feature, use the Feature Request template.
- **Documentation**: If something is unclear or missing in the docs, open an issue using the Documentation template.

### 4. Ask a Question
If you just have a question on how to use Backify, you can start a [GitHub Discussion](https://github.com/your-username/backify/discussions) (if enabled) or open an issue with the `question` label.

We aim to respond to issues and questions as quickly as possible. Thank you for using and supporting Backify!
